# 🏥 Hospital Management System

A full-stack Hospital Management System designed to manage patients, doctors, appointments, and hospital operations efficiently.

---

## 🚀 Features

### 🔐 Authentication
- JWT-based login & registration
- Role-based access (Admin / Doctor / Patient)

### 👨‍⚕️ Doctor Module
- View assigned patients
- Manage appointments
- Update patient records

### 🧑‍🤝‍🧑 Patient Module
- Book appointments
- View prescriptions
- Track medical history

### 🛠 Admin Module
- Manage doctors & patients
- View system reports
- Control hospital operations

---

## 🧰 Tech Stack

### Frontend
- Next.js / React
- Tailwind CSS

### Backend
- Spring Boot / FastAPI (depending on your setup)

### Database
- MongoDB

### Authentication
- JWT (JSON Web Token)
